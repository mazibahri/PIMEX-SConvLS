# SConvLS interactive dashboard

[Open the dashboard](https://mazibahri.github.io/PIMEX-SConvLS/dashboard/)

Explore 30 saved final-test scenarios, excavation phases, five-step settlement predictions and nominal 95% pointwise bands. Select a surface node to update its trajectory and transverse/longitudinal profiles. Includes schematic twin-tunnel geometry and light/dark themes.

This version displays precomputed results; parameter values are read-only. No FLAC3D simulation or model inference runs in the browser. Geometry and EPB positions are illustrative. Prediction bands describe surrogate errors relative to FLAC3D, not engineering safety limits.

The data folder contains the display-ready reference and prediction fields required by the dashboard. All assets are served locally with relative URLs.
